# 機能の詳細・検証記録

[READMEに戻る](../README.md)


Chromeの拡張機能メニューから「ととのえっくす for X」を開きます。よく使う場合はピン留めしてください。説明は各オプションの直下に表示します。5機能とも最初はオンで、変更は自動保存されます。開いているXにも変更を反映します。

- 基本：共有をURLコピーに、メディアの既定を画像に。
- Grok：ポストのGrokボタンを隠す、画像の編集ボタンを隠す。
- プレミアム：プレミアムの案内を隠す。

各カテゴリを1つの一覧に表示します。画面の下にある設定は縦にスクロールして操作できます。これまでの設定値も引き継ぎます。

表示言語はChrome標準のローカライズ機能で自動選択します。X側の言語設定には連動せず、Xの言語も変更しません。設定画面・拡張機能情報・コピーのボタン名と結果通知・エラー・再試行が翻訳対象です。ブラウザのダーク設定にも自動追従します。

### 共有をURLコピーに

ホームの投稿の右端に、共有アイコンに代わってコピーアイコンが表示されます。クリックすると `https://x.com/ユーザー名/status/投稿ID` を直接コピーします。成功時は緑のチェック、失敗時は赤いマークになります。キーボードのTabで移動し、EnterまたはSpaceでも操作できます。

投稿のURLは押した時点で表示済みDOMから取得します。標準共有メニュー・投稿詳細・Xの内部共有関数は呼びません。クエリとフラグメントはコピーしません。引用を含む投稿では、外側の投稿のURLが対象です。

### メディアの既定を画像に

プロフィールのメディアを開いたとき、X標準のメニューで画像を選びます。タブ全体の再読み込みは行いません。すでに `filter` を指定したURLは変更しません。

Xのタブが描画されるまで待ち、自動で開いたメニューだけを次の描画前に隠して画像を選びます。手動操作が入った場合は自動切替を止めます。メニューの構造が未知の場合やXの処理が準備できていない場合は切り替えず、再読み込みで代替することもしません。

その後同じプロフィールで自分で動画に切り替えた場合は、画像へ戻しません。別のプロフィールのメディアに入った場合や、ページを新たに開いた場合は再び画像を初期選択します。オフにしても現在の画像表示を勝手に動画へ変えることはありません。

### プレミアムの案内を隠す

0.3.0で追加。次のUIをまとめて非表示にします。設定をオフにすると、Xを再読み込みせず元の表示へ戻せます。

- サイドメニューの「プレミアム」。
- ホーム右側の「プレミアムにサブスクライブ」カード。
- 自分のプロフィールの「まだ認証されていません」カード。
- 認証済みアカウントのプロフィールに出る、自分が未認証であることを知らせる加入案内。

認証バッジやプロフィール名、フォロワー数、自己紹介、通常の投稿は残します。非表示はブラウザ内だけの処理で、案内の閉じるボタンや加入ボタンを押すものではありません。再描画された案内も対象にし、Xが同じコンテナを通常の内容に再利用した場合は表示を復元します。未知の案内は無理に隠しません。

### ポストのGrokボタンを隠す

0.4.0で追加。投稿右上の、ホバー時に「このポストを説明する」と出るGrokボタンを隠します。サイドメニューのGrok、Grokドロワー、画像生成などの入口は残します。

### 画像の編集ボタンを隠す

0.4.0で追加。投稿画像に出る「画像を編集」などの編集入口を隠します。ホバーで後から追加される場合や、ボタンではなくリンクになっている場合にも対応します。画像ビューアーの同じ入口も対象にしますが、投稿作成時の添付画像編集・プロフィール編集は残します。画像そのものの閲覧には手を加えません。

画像編集の入口は調査用のXセッションでは表示されませんでした。Xが配信する画像編集コンポーネントと専用SVGを読取り、確認済みの図柄と画像の周辺構造を併用しています。ボタン・リンク・ホバー追加のブラウザfixtureで検証していますが、本人のChrome上で実際に非表示になるかの最終確認は残っています。

## 対応範囲と限界

- 直接コピーはホーム画面（おすすめ／フォロー中の同じ記事構造）が対象です。検索・プロフィール・投稿詳細・メディア画面では共有ボタンを置換しません。返信とリポストの操作がある欄から、専用IDを持たない唯一のメニュー入口を識別します。
- 画像の初期選択はプロフィールのメディア画面が対象です。filterなしの動画表示から開いた2項目のメニューで、選択チェックと未選択項目を識別します。項目名や並び順は使いません。
- 対象識別に特定言語の文言は使いませんが、全言語・全A/Bテストの実画面を確認したものではありません。Grok・画像編集・チェック・閉じるの専用IDがない箇所では、文脈と観測済みSVGを組み合わせます。図柄やDOMが変わって一致しなくなった場合は操作しません。Xの内部モジュールやアカウント設定には依存しません。
- 識別できない投稿や未知のDOM構造は、元の共有ボタンを残します。Xの更新で動かなくなる可能性があります。
- おすすめへの影響ゼロ、匿名化、Xの全計測の停止を保証するものではありません。表示・滞在などの計測は残ります。
- 独自ボタンの操作はwindow captureで処理し、後続のroot captureや標準共有へ伝播させません。先行するwindowリスナーなど、すべての観測経路を遮断できるとは扱いません。
- 書込み失敗時に標準共有へフォールバックしません。再度押しても失敗する場合はChromeのサイトアクセス設定等を確認してください。
- 削除・無効化・更新した後はXを再読み込みしてください。読み込み済みcontent scriptはブラウザの仕様上、ページ再読み込みまで残る場合があります。

## 権限・データ

要求するAPI権限は `clipboardWrite`（コピー）と `storage`（設定保存）です。content scriptの対象は `https://x.com/*` で、実際のボタン置換は `/home` に限定しています。SPAでホームやメディア画面へ移動した時にも動作するため、URLの指定はX全体です。

クリップボードの読取り、Cookie取得、アカウント情報取得、閲覧履歴保存、外部への送信処理は実装していません。投稿本文を保存しません。保存するのは5つのオン・オフだけで、Chromeのローカル領域を使います。アカウント連携・APIキー・追加ログインは不要です。ポップアップのフォントやコードは外部へ取りに行きません。

## 検証

ログイン済みの実Xではホームの表示済み9投稿を調べ、共有ボタンと投稿URLを特定しました。またプロフィールのメディアで「画像」を選ぶと `?filter=photo` になり、「動画」に戻すとfilterが消えることを確認しました。0.2.1の調査では、通常遷移を抑止したメニュー操作でも画像選択が成立し、ページのtimeOriginが変わらないことを実Xで確認しています。拡張機能を入れた実X上での本人操作、実Xの計測通信への影響は未検証です。

自動テストでは匿名のDOM fixtureを用い、Playwright付属Chromiumへ実際のMV3拡張として読み込んでいます。

0.7.0では、Chrome自体を日本語・英国英語・フランス語で起動し、日英の選択と未対応言語からの英語フォールバックを確認しています。設定の保存と再読込、読込/保存/コピーのエラー、再試行、読み上げ用の通知と言語指定、実action popupの日英の幅・スクロールも検証しています。

0.6.0では、ラベルの翻訳・削除、メディア項目の並び替え、未知のメニュー、図柄の再利用、投稿本文や作成画面の保護を含め46テストを確認しました。実Xでもホーム8投稿の共有候補がそれぞれ1件になること、非表示処理の復元、自分のプロフィールの加入案内だけが隠れること、メディアの画像切替でtimeOriginが変わらないことを確認しています。

0.3.0の非表示処理は、実Xのホーム・自分のプロフィール・認証済み相手のプロフィールでも一時適用し、4種類の案内の非表示と復元、プロフィール名の維持を確認しました。確認後は元に戻しています。実拡張としての読み込み・設定連携は以下のブラウザテストで検証しています。

- 引用・写真・analyticsとの区別、URLの正規化。
- マウス・キーボード・タッチでの実コピーとOSクリップボードからの読戻し。
- ページのroot capture／標準共有ハンドラーに操作が届かず、コピー用通信が発生しないこと。
- DOM再利用・追加・再描画、曖昧なヘッダーや外部URLでの非置換、ホーム離脱時の復元。
- ページJavaScriptが作った合成クリック・キー入力ではクリップボードを変更しないこと。
- コピー失敗の表示。このケースだけOSエラーを拡張機能のテスト用実行環境で注入します。正常経路のクリップボードは実物です。
- 設定の保存・再読込・開いているタブへの反映、画像初期選択・手動動画切替の尊重・SPA遷移・設定オフ。
- 画像切替時の文書リクエスト数・文書固有値の維持、遅延描画・未準備リンクの通常遷移防止・手動介入時の中止。
- ポップアップの個別切替と各項目内の説明表示。設定画面は380px・390px・1280pxで撮影・DOM監査しています。説明を項目の下に置くのは本人の希望です。
- 通常タブとは別に、chrome.action.openPopupで実際のツールバーポップアップを開く回帰テスト。380px幅の一覧をスクロールし、末尾のプレミアム設定をクリックして保存できることを検証しています。
- プレミアム案内4種類、周辺情報の保護、オン/オフでの即復元と元のinline styleの保持、再描画・追加表示・コンテナ再利用、設定の独立保存。
- 投稿のGrok説明と画像編集の個別非表示、ホバー追加、リンク型の編集入口、DOM再利用時の復元、投稿作成/プロフィール編集の保護。

実XのDOMや推薦処理を完全再現するテストではありません。
