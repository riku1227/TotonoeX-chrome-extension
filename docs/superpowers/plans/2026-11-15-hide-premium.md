# プレミアム案内の非表示

本人指定の4種類を1つの設定で隠す。追加確認不要で既存の方式に合わせて実装する。

- [x] 実Xのサイドメニューpremium-signup-tab、sidebarのaside、自己プロフィールの加入カード、認証済み相手のverified_profile_visitor_upsellを観測。
- [x] 先に実MV3テストを追加し、未実装で非表示にならない失敗を確認。
- [x] extension/premium.jsに識別とスタイルの保存/復元を分離し、既存の設定・DOM監視へ接続。
- [x] 投稿本文、プロフィール自己紹介、認証バッジ、フォロワー欄を保護。未知カードは隠さない。
- [x] 3項目目の設定をポップアップへ追加し、説明はその直下へ。
- [x] オフ即復元・再描画・DOM再利用・追加表示・独立保存のブラウザテスト。
- [x] lint・撮影/目視・DOM監査・配布ZIPとCraft記録を更新。

追加権限と外部通信は不要。加入ボタンを押したり、案内をX側で閉じたりせず、ローカルの表示だけを変える。
