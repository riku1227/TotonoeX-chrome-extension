# Privacy Policy / プライバシーポリシー

TotonoeX for X / ととのえっくす for X  
Last updated / 最終更新: 2026-11-15

## 日本語

ととのえっくす for X は、X（x.com）の表示と操作を調整する拡張機能です。

- 開発者は、この拡張機能を通じて個人情報、閲覧履歴、投稿内容、アカウント情報を収集しません。解析・広告・追跡用の通信は行わず、外部サーバーへデータを送信しません。
- 表示中のXページのURLやDOMをブラウザ内で処理し、URLコピー、メディアの初期選択、指定されたUIの非表示に使用します。ページ内容は保存しません。
- コピー操作時に投稿URLをシステムのクリップボードへ書き込みます。クリップボードの読み取りは行いません。コピーしたURLは、上書き・削除するまでクリップボードに残る場合があります。
- 5つの機能のオン・オフ設定のみを `chrome.storage.local` に保存します。拡張機能はこれらを外部へ送信しません。アンインストールすると拡張機能の保存設定は削除されます。
- ユーザーデータの販売、第三者への転送、信用評価や融資への利用は行いません。
- XおよびChrome自体によるデータの取り扱いは、それぞれのサービスのポリシーに従います。この拡張機能はXによる計測の停止を保証しません。

お問い合わせ: [GitHub Issues](https://github.com/riku1227/TotonoeX-chrome-extension/issues)。公開のため、個人情報や認証情報は投稿しないでください。

## English

TotonoeX for X adjusts the interface and browsing controls on X (x.com).

- The developer does not collect personal information, browsing history, post content, or account information through this extension. It contains no analytics, advertising, or tracking communications and sends no data to external servers.
- The extension processes the displayed X page's URL and DOM locally in the browser to copy post URLs, select the initial Media filter, and hide selected interface elements. Page content is not stored.
- When you activate the copy feature, a post URL is written to the system clipboard. The extension does not read the clipboard. A copied URL may remain in your clipboard until replaced or cleared.
- Only the five on/off feature preferences are saved in `chrome.storage.local`. The extension does not transmit these preferences externally. Uninstalling the extension removes its stored preferences.
- User data is not sold, transferred to third parties, or used for creditworthiness or lending purposes.
- Data handling by X and Chrome themselves is governed by their respective policies. This extension does not guarantee that X stops measuring activity.

Contact: [GitHub Issues](https://github.com/riku1227/TotonoeX-chrome-extension/issues). Issues are public; do not include personal information or credentials.
